Java Streams

Daten mit Stream-Pipelines filtern, umwandeln, sortieren und zusammenfassen

Start Grundlagen Operationen Stream-Typen Collect & Gruppieren flatMap Übungen

Was sind Streams?

Mit der Stream-API können Elemente einer Datenquelle, zum Beispiel einer List , in einer Verarbeitungskette bearbeitet werden. Ein Stream ist keine neue Collection und speichert selbst keine Elemente. 

List<Integer> numbers = List.of(12, 9, 13, 6, 23, 1, 289);
numbers.stream()
       .filter(n -> n % 2 != 0)
       .forEach(System.out::println); // 9, 13, 23, 1, 289

Du kennst Lambdas und Methodenreferenzen bereits. In Streams werden sie an Operationen wie filter und map übergeben. Die Beispiele verwenden Java 17 oder neuer, insbesondere Stream.toList() (seit Java 16).

Aufbau einer Stream-Pipeline

Eine Pipeline besteht aus Quelle , beliebig vielen intermediären Operationen und einer terminalen Operation . 

List<String> result = List.of("Spring", "API", "Docker").stream() // Quelle
    .filter(s -> s.length() > 3)                       // intermediär
    .map(String::toUpperCase)                          // intermediär
    .toList();                                         // terminal
System.out.println(result); // [SPRING, DOCKER]

Intermediäre Operationen sind lazy : Sie werden erst durch eine terminale Operation ausgeführt. Ein Stream kann nach einer terminalen Operation nicht nochmals verwendet werden; er muss neu erzeugt werden.

Häufige Operationen

filter, map, sorted und limit 

List<Integer> result = List.of(3, 12, 5, 10, 7).stream()
    .filter(n -> n > 4)                       // 12, 5, 10, 7
    .map(n -> n * n)                          // 144, 25, 100, 49
    .sorted(Comparator.reverseOrder())       // 144, 100, 49, 25
    .limit(3)
    .toList();
System.out.println(result); // [144, 100, 49]

filter erwartet ein Predicate<T> ; map erwartet eine Function<T,R> . sorted und limit verändern nicht die Ausgangsliste.

findFirst, max und reduce 

Optional<String> first = List.of("Java", "API").stream().findFirst();
System.out.println(first.orElse("Kein Element"));

int sum = List.of(1, 2, 3).stream().reduce(0, Integer::sum);
System.out.println(sum); // 6

findFirst() und max() liefern ein Optional , weil der Stream leer sein könnte. reduce fasst mehrere Elemente zu einem Ergebnis zusammen.

Primitive Streams: IntStream

Für primitive Zahlen gibt es IntStream , LongStream und DoubleStream . Damit sind Operationen wie sum() und average() direkt möglich. 

int sum = IntStream.rangeClosed(1, 10).sum(); // 55
int sum2 = List.of(1, 2, 3).stream()
    .mapToInt(Integer::intValue)
    .sum(); // 6
List<String> texts = IntStream.of(12, 9, 13)
    .mapToObj(String::valueOf)
    .toList();

rangeClosed(1, 10) schließt die 10 ein; range(1, 10) nicht. mapToInt wechselt von Stream<Integer> zu IntStream , mapToObj zurück zu einem Objekt-Stream.

Ergebnisse sammeln und gruppieren

toList() liefert seit Java 16 eine nicht veränderbare Liste. Mit collect(Collectors.toList()) erhält man eine Liste, deren konkrete Implementierung und Veränderbarkeit nicht zugesichert sind. 

List<String> words = List.of("Java", "API", "Lambda");
Map<Integer, List<String>> byLength = words.stream()
    .collect(Collectors.groupingBy(String::length));
// {3=[API], 4=[Java], 6=[Lambda]}

String joined = words.stream()
    .collect(Collectors.joining(", ", "[", "]"));
// [Java, API, Lambda]

groupingBy liefert eine Map , deren Schlüssel aus einer Funktion entstehen. Für die Anzahl der Elemente pro Gruppe eignet sich Collectors.counting() .

Verschachtelte Listen mit flatMap

map erzeugt aus jedem Element genau ein neues Element. flatMap kann aus jedem Element einen Stream erzeugen und diese Streams zu einem einzigen Stream zusammenführen. 

List<List<String>> nested = List.of(
    List.of("c", "a"), List.of("b", "d"));
List<String> flat = nested.stream()
    .flatMap(List::stream)
    .sorted()
    .toList();
System.out.println(flat); // [a, b, c, d]

4. Personen: Durchschnitt und Gruppierung

Erstelle drei Personen mit Namen und Alter, berechne das Durchschnittsalter und gruppiere die Personen nach ihrem Alter ( groupingBy ).

Nutze averagingInt(Person::getAge) und groupingBy(Person::getAge).

Die Klasse Person wird auch in Aufgabe 10 verwendet. Die Gruppierung liefert eine Map<Integer, List<Person>> . 

class Person implements Comparable<Person> {
    private final String name;
    private final int age;

    Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
    String getName() { return name; }
    int getAge() { return age; }
    @Override public int compareTo(Person other) {
        return name.compareTo(other.name);
    }
    @Override public String toString() {
        return name + " (" + age + ")";
    }
}

List<Person> people = List.of(
    new Person("Susi", 30),
    new Person("Anton", 30),
    new Person("Strolchi", 15));

double average = people.stream()
    .collect(Collectors.averagingInt(Person::getAge));
Map<Integer, List<Person>> byAge = people.stream()
    .collect(Collectors.groupingBy(Person::getAge));
System.out.println(average); // 25.0
System.out.println(byAge);

14. Zeichenhäufigkeit zählen

Zähle die Häufigkeit aller Zeichen in "hello world" , ohne Leerzeichen.

String.chars() liefert IntStream; mapToObj wandelt Zeichenwerte um.

Die Reihenfolge der Schlüssel in der Map ist nicht garantiert. Anders als Character::isLetter entfernt der Filter hier nur Leerzeichen, wie gefordert. 

String text = "hello world";
Map<Character, Long> frequency = text.chars()
    .mapToObj(c -> (char) c)
    .filter(c -> c != ' ')
    .collect(Collectors.groupingBy(c -> c, Collectors.counting()));
System.out.println(frequency);
// d=1, e=1, h=1, l=3, o=2, r=1, w=1

18a. Schleife durch Stream ersetzen: Map-Einträge

Wandle eine Schleife um, die aus Namen und Alter Strings der Form "Alice is 25 years old" erzeugt.

Map.entrySet().stream() liefert Einträge; map formatiert jeden Eintrag.

Die Reihenfolge der Einträge einer HashMap ist nicht garantiert. 

Map<String, Integer> ages = new HashMap<>();
ages.put("Alice", 25);
ages.put("Bob", 30);
ages.put("Charlie", 35);

List<String> result = ages.entrySet().stream()
    .map(e -> e.getKey() + " is " + e.getValue() + " years old")
    .toList();
System.out.println(result);

18b. Schleife durch Stream ersetzen: Anfangsbuchstaben

Gruppiere die Namen Alice , Bob , Charlie , Anna und Chris nach ihrem ersten Buchstaben.

groupingBy mit name.charAt(0). 

List<String> names = Arrays.asList("Alice", "Bob", "Charlie", "Anna", "Chris");
Map<Character, List<String>> grouped = names.stream()
    .collect(Collectors.groupingBy(name -> name.charAt(0)));
System.out.println(grouped);
// {A=[Alice, Anna], B=[Bob], C=[Charlie, Chris]}

18c. Schleife durch Stream ersetzen: Map filtern

Übernimm aus einer Map mit Alice=25 , Bob=30 und Charlie=35 nur Einträge mit Alter über 28 in eine neue Map.

filter auf entry.getValue() und collect mit Collectors.toMap.

Die Reihenfolge der Schlüssel ist nicht garantiert. 

Map<String, Integer> m1 = Map.of("Alice", 25, "Bob", 30, "Charlie", 35);
Map<String, Integer> m2 = m1.entrySet().stream()
    .filter(e -> e.getValue() > 28)
    .collect(Collectors.toMap(Map.Entry::getKey, Map.Entry::getValue));
System.out.println(m2); // Bob=30, Charlie=35
